# SAMNKOSI Technology Group

Official website for SAMNKOSI Technology Group.

## Technology Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

http://localhost:3000

## Build

```bash
npm run build
```
